# Study workspace

Mode: Operate, with a Read-mode answer surface. Target: app/page.tsx and the
three workbench views. Preserve existing content, backend contracts, and all
conversation/library/study actions. User approved conversation-first, dark-only,
code-led implementation and the focused workspace direction. Fresh startup is a
new conversation; drawers and evidence remain closed until requested.

## Direction contract

THESIS: A focused study desk: navigation and history live in one column; answers
own the reading surface; evidence is progressively disclosed. No second desktop
navigation header, decorative cards, glass, or dashboard opening screen.

OWN-WORLD: Opaque graphite #111214 content, #191a1e navigation, #27292f raised
controls, #f1f2f4 text, and #8fb8ee functional accent. System sans, zero tracking,
6-8px control corners, subtle separators, deliberate vertical rhythm.

STORY: Launch into a clean question surface. Ask, read, inspect a citation when
needed, continue, or reopen a saved conversation. Library and study tools are
secondary views with the same shell and control language.

FIRST VIEWPORT: A 256px desktop sidebar holds brand, new-chat action, three nav
items, compact searchable history, and connection status. A single 64px main
toolbar holds title and secondary actions. An 860px desktop conversation column
and composer use 16px reading text, widened at the user's explicit request.
Mobile replaces navigation with a closed drawer.

FORM: Research desk/document-navigation workspace, grounded candidate 4,
concept seed 966ed199. Compact-row discipline, clear wayfinding, aligned source
labels, and contained diagnostics raise the execution. No physical desk imagery.

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
